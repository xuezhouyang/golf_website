# SMS2Email 离线激活码系统

## 🔐 系统概述

SMS2Email v2.0.0 现在使用 **Windows 7风格的离线激活码系统**，完全解耦，不依赖任何在线服务。

### 核心特性

✅ **完全离线验证** - 无需服务器，无需网络
✅ **设备绑定** - 每个激活码绑定特定设备
✅ **防爆破保护** - 10次失败后锁定24小时
✅ **多订阅层级** - 支持1天试用/永久订阅等
✅ **便于输入** - Base32编码，无混淆字符

---

## 📋 激活码格式

```
XXXXX-XXXXX-XXXXX-XXXXX-XXXXX
  ↓      ↓      ↓      ↓      ↓
版本  订阅类型  设备指纹  签名  校验
```

**示例**: `A2B4C-D6E8F-G2H4J-K6L8M-N2P4Q`

## 🛠️ 作者使用指南

### 1. 生成激活码

打开 `activation_code_generator.html` 文件（浏览器中打开即可）

#### 输入信息：
- **设备ID (Android ID)**: 用户从应用中获取
- **设备型号**: 用户从应用中获取
- **订阅类型**: 选择订阅层级

#### 订阅类型：
| 类型 | 代码 | 有效期 |
|------|------|--------|
| 试用1天 | TRIAL_1_DAY | 1天 |
| 试用7天 | TRIAL_7_DAY | 7天 |
| 月度订阅 | MONTHLY | 30天 |
| 年度订阅 | YEARLY | 365天 |
| **永久订阅** | **PERMANENT** | **永久** |

#### 批量生成：
设置"批量生成数量"可以为不同设备生成多个激活码（用于不同设备，每个设备ID会自动递增）

### 2. 发放激活码

1. 用户在应用的 "Premium" 界面查看设备信息
2. 用户将设备ID和型号发送给作者
3. 作者使用HTML工具生成激活码
4. 将激活码发送给用户
5. 用户在应用中输入激活码激活

## 👤 用户使用指南

### 获取设备信息

1. 打开SMS2Email应用
2. 进入 **Premium订阅** 界面
3. 点击"显示设备信息"
4. 复制设备ID和设备型号
5. 发送给作者获取激活码

### 激活流程

1. 从作者处获得激活码
2. 打开应用 → **Premium订阅**
3. 输入激活码（格式：`XXXXX-XXXXX-XXXXX-XXXXX-XXXXX`）
4. 点击 **激活Premium**
5. 激活成功！

## 🔒 安全机制

### 防爆破保护

| 失败次数 | 延迟时间 |
|----------|----------|
| 1次 | 1秒 |
| 2次 | 2秒 |
| 3次 | 4秒 |
| 4次 | 8秒 |
| 5次 | 16秒 |
| 6次 | 32秒 |
| 7次 | 64秒 |
| 10次 | **锁定24小时** |

### 设备绑定

- 激活码基于 `Android ID + 设备型号` 生成
- 无法在其他设备上使用
- 换设备需要重新获取激活码

## 🔧 技术实现

### 核心文件

1. **ActivationCodeGenerator.kt** - 激活码生成和验证算法
   - HMAC-SHA256签名
   - Base32编码（无混淆字符）
   - 设备指纹计算

2. **ActivationManager.kt** - 激活管理器
   - 防爆破机制
   - EncryptedSharedPreferences存储
   - 订阅状态管理

3. **activation_code_generator.html** - 作者发码工具
   - 纯前端JavaScript实现
   - 完整算法复制
   - 批量生成支持

### 算法特点

```kotlin
激活码 = Base32Encode(
    版本号(1字节) +
    订阅类型(1字节) +
    发布日期(4字节) +
    设备指纹(4字节) +
    HMAC签名(11字节)
)
```

- **主密钥**: `SMS2EMAIL_MASTER_SECRET_KEY_2025`（硬编码）
- **字符集**: `ABCDEFGHJKLMNPQRSTUVWXYZ23456789`（去掉0,O,1,I）
- **总长度**: 20字节 → 25字符（分5组）

## ⚠️ 重要提示

1. **主密钥保密**: `SMS2EMAIL_MASTER_SECRET_KEY_2025` 不得泄露
2. **HTML工具保密**: `activation_code_generator.html` 仅供作者使用
3. **激活码唯一**: 每个激活码只能用于一个设备
4. **不可逆向**: 算法使用HMAC签名，无法通过激活码反推主密钥
